# Catálogo de productos

## Estructura del producto

Cada producto se define por:

- Línea
- Modelo comercial
- Tecnología
- Altura
- Tipo de pillow
- Medida
- Presentación: colchón o conjunto

## Presentaciones

- Solo colchón
- Conjunto con sommier

Hasta 150 cm, el sommier es de una sola pieza.
Desde 160 cm, se divide en dos bases iguales.

## Reglas de comunicación

- Separar siempre el nombre comercial de la tecnología.
- No inventar firmeza, peso soportado, garantía ni composición interna.
- No presentar pillow, altura o tela como opciones configurables.
- El cliente elige modelo, medida y presentación.
